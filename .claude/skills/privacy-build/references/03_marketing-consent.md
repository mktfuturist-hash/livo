# 마케팅 수신동의 — 동의 문구와 발송 규칙

마케팅 수신동의는 **문서 한 장이 아니라 세 덩어리**다. 셋을 다 만들어야 한다.

| 덩어리 | 무엇 |
|---|---|
| **① 동의받는 화면** | 체크박스 문구 + 상세 안내 |
| **② 발송하는 메시지** | "(광고)" 표기 · 수신거부 안내 |
| **③ 기록과 운영** | 동의 일자 저장 · 철회 처리 · 2년 재확인 |

---

## ① 동의받는 화면

### 절대 규칙

1. **필수 동의와 분리한다.** 이용약관·개인정보 동의와 한 체크박스로 묶으면 안 된다.
2. **기본값은 체크 해제.** 미리 체크해 두지 않는다.
3. **매체를 열거한다.** "SMS 동의"만 받고 카카오톡으로 보내면 위법 소지가 있다.
4. **"혜택 알림", "정보 제공" 같은 모호한 표현을 쓰지 않는다.** KISA 7차 안내서가 명시적으로 지적한다. **"광고성 정보"라는 말이 들어가야 한다.**
5. **야간(21시~익일 08시) 발송은 별도 동의**다. 안 받을 거면 그 시간에 안 보내면 된다.

### 체크박스 문구 (권장)

```
☐ [필수] 서비스 이용약관에 동의합니다                        [전문 보기]
☐ [필수] 개인정보 수집·이용에 동의합니다                      [전문 보기]
☐ [선택] 광고성 정보 수신에 동의합니다                        [자세히]
        └ ☐ 이메일   ☐ 문자(SMS)   ☐ 카카오톡   ☐ 앱 푸시
☐ [선택] 야간(21시~익일 08시) 광고성 정보 수신에 동의합니다
```

**하위 채널 체크박스를 두는 게 가장 안전하다.** UI를 줄여야 한다면 최소한 문구에 매체를 열거한다.

> ☐ [선택] **이메일·문자·카카오톡·앱 푸시**를 통한 광고성 정보 수신에 동의합니다

야간 동의를 안 받을 거라면 그 줄을 지우고, **21시~08시에는 발송하지 않도록 코드에서 막는다.**

### 상세 안내 문구 (「자세히」 클릭 시)

```markdown
### 광고성 정보 수신 동의 안내

**수신 동의 시 받게 되는 정보**
[[신규 서비스·기능 안내, 이벤트 및 할인 정보, 콘텐츠 소식]]

**전송 매체**
[[이메일, 문자메시지(SMS/LMS), 카카오톡, 앱 푸시 알림]]

**보유·이용 기간**
동의를 철회하실 때까지

**동의를 거부하실 수 있습니다**
이 동의는 선택 사항입니다. 동의하지 않으셔도 서비스 이용에는 제한이 없습니다.
다만 광고성 정보를 받아보실 수 없습니다.

**철회 방법**
- [[서비스 내 설정 > 알림 설정]]에서 언제든지 변경하실 수 있습니다
- 발송된 메시지의 수신거부 링크 또는 무료 수신거부 번호를 이용하실 수 있습니다
- [[문의 이메일]]로 요청하셔도 됩니다

**야간 수신**
오후 9시부터 다음 날 오전 8시 사이의 발송은 별도 동의를 받은 경우에만 이루어집니다.

**수신 동의 확인**
관련 법령에 따라 동의하신 날부터 2년마다 수신 동의 여부를 확인해 드립니다.
```

## ② 발송하는 메시지

### 공통

- **"(광고)"를 그대로** 쓴다. `(광 고)`, `[AD]`, `(광고)` 대신 이모지 — 전부 회피 표기로 위반이다.
- 수신거부·철회할 때 **연락처 외의 정보를 요구하지 않는다.** 로그인·본인인증을 요구하면 형사처벌 대상이다.
- 수신거부 **비용을 이용자가 부담하지 않게** 한다.

### 이메일

```
제목: (광고) [[서비스명]] [[제목 내용]]
```
**"(광고)"는 제목이 시작되는 부분에.** 중간에 넣으면 안 된다.

본문 하단에 반드시:
```
─────────────────────────────
[[서비스명]]
[[상호 또는 운영자명]] | [[이메일]] | [[전화번호]]
[[주소]]

이 메일은 광고성 정보 수신에 동의하신 분께 발송되었습니다.
수신을 원하지 않으시면 [수신거부]를 눌러주세요.

This is an advertisement. If you do not wish to receive
these emails, please click [Unsubscribe].
─────────────────────────────
```

**수신거부 안내는 한글과 영문 병기.** 그리고 **원클릭 수신거부**가 되어야 한다. 로그인을 요구하면 안 된다.

### 문자 (SMS / LMS)

```
(광고) [[서비스명]]
[[본문]]

무료수신거부 [[080-XXX-XXXX]]
```

- "(광고)"는 **맨 앞**
- 수신거부 방법은 **맨 끝**
- **"무료"라는 단어가 반드시 들어가야 한다** — 가장 흔한 누락
- 080 무료 수신거부 번호는 발송 대행사(Solapi 등)에서 발급받는다

### 카카오 — 알림톡 vs 친구톡

| | 알림톡 | 친구톡 |
|---|---|---|
| 성격 | **정보성** | **광고성** |
| 대상 | 채널 미추가자에게도 발송 가능 | 채널 친구 |
| 마케팅 수신동의 | 불필요 | **필요** |
| "(광고)" | 불필요 | **필요** |
| 야간 제한 | 해당 없음 | **적용** |
| 조건 | 템플릿 심사 승인 + 적법 수집 번호 | — |

**알림톡으로 보낼 수 있는 것** — 신청 접수 확인, 결제 완료, 배송 안내, 예약 확정처럼 **수신자가 반드시 인지해야 하는 필수 정보.**

**함정** — 정보 중심으로 쓰였더라도 **특가·할인·프로모션·이벤트가 섞이면 광고성**이 된다. "신청이 접수되었습니다" 아래에 "지금 가입하면 20% 할인"을 붙이는 순간 알림톡으로 못 보낸다.

**⚠️ KISA 7차 안내서 기준으로 일방 지급한 쿠폰·마일리지·적립금 안내도 광고성이다.** "쿠폰이 지급되었습니다"는 사전 동의가 필요하다.

### 앱 푸시

- **OS의 "알림 허용"은 마케팅 수신동의가 아니다.** 서비스 안에서 별도로 받아야 한다.
- 음성 외 형태이므로 "(광고)" + 전송자 명칭 + 끝부분에 수신거부 방법·무료 명시
- **알림 거부 절차를 복잡하게 만들지 않는다.** 로그인을 요구하면 안 된다 (KISA 7차)

### 야간 발송 (21:00 ~ 익일 08:00)

- **문자·앱 푸시·친구톡** → 별도 동의 없으면 발송 금지
- **이메일** → 야간 별도 동의 대상에서 예외
- 별도 동의를 안 받았다면 **코드에서 발송 시각을 막는 게 안전하다**

## ③ 기록과 운영

### DB에 반드시 남길 것

```sql
marketing_consent          boolean   default false,
marketing_consent_at       timestamptz,   -- 2년 재확인의 기준점
marketing_consent_channels text[],        -- ['email','sms','kakao','push']
marketing_consent_night    boolean   default false,
marketing_consent_version  text,          -- 동의받은 문구의 버전
marketing_revoked_at       timestamptz    -- 철회 시각
```

> **`marketing_consent`를 boolean 하나로만 저장하면 2년차에 손쓸 수 없다.**
> 법이 요구하는 재확인은 "동의일로부터 2년"이고, 확인할 때 **동의한 날짜를 고지**해야 한다.
> 개별 이용자마다 시계가 따로 돌기 때문에 서비스 오픈일 기준으로는 계산이 안 된다.
> **스키마 단계에서 결정되는 문제라 나중에 고치기가 가장 어렵다.**

### 2년마다 재확인

동의일로부터 2년이 되는 시점에 아래를 고지한다.

```
[[서비스명]] 광고성 정보 수신 동의 안내

회원님께서는 [[YYYY년 MM월 DD일]] 광고성 정보 수신에 동의하셨습니다.
관련 법령에 따라 2년마다 동의 여부를 확인해 드리고 있습니다.

계속 받아보시려면 별도의 조치가 필요하지 않습니다.
더 이상 원하지 않으시면 아래에서 철회하실 수 있습니다.

[수신 철회하기]
```

**고지에 반드시 들어가야 하는 것** — ① 전송자의 명칭 ② 수신동의 사실과 **동의한 날짜** ③ 유지 또는 철회 의사표시 방법.

이건 문서가 아니라 **운영 절차**다. 자동화하거나 캘린더에 넣지 않으면 반드시 놓친다.

### 철회 처리

- 철회 의사를 받으면 **처리 결과를 알려야 한다** (정보통신망법 제50조 제7항)
- 철회한 사람에게는 발송하지 않는다
- 철회 기록도 남긴다 — "안 보냈다"의 증거

## 거래관계 예외 — 동의 없이 보낼 수 있는 경우

거래로 **직접 수집한** 연락처에, **거래 종료일부터 6개월 이내**, **동종** 재화등의 광고를 보내는 경우는 사전 동의 예외다.

**세 조건이 모두 맞아야 한다.**
- 거래를 통해 직접 받은 연락처 (제3자에게 받은 것 ✕)
- 6개월 이내
- **동종** — 커피 원두를 산 고객에게 원두 신제품은 여지가 있지만, 같은 회사가 파는 다른 카테고리는 안 된다

**무료 신청 폼으로 받은 이메일은 "거래관계"가 아니다.** 예외에 기대지 말고 동의를 받는다.

## 과태료

| 위반 | 금액 |
|---|---|
| 동의 없이 전송 / 수신거부자에게 전송 / 야간 별도 동의 없이 전송 | 3천만원 이하 |
| 표시의무 미이행 ("(광고)" 누락 등) | 3천만원 이하 |
| 2년 재확인 미실시 | 3천만원 이하 |
| **수신거부 회피·방해, 자동 연락처 생성·등록, 신원 은폐** | **1년 이하 징역 또는 1천만원 이하 벌금** |

실제 부과 기준 — 1차 750만원 / 2차 1,500만원 / 3차 3,000만원.

## 완성 후 확인

```
□ 마케팅 동의가 필수 동의와 분리되어 있다
□ 기본값이 체크 해제다
□ 문구에 매체가 열거되어 있다
□ "광고성 정보"라는 말이 들어 있다 ("혜택 알림" ✕)
□ 발송 템플릿에 "(광고)"가 규칙에 맞는 위치에 있다
□ 문자에 "무료수신거부"가 들어 있다
□ 이메일 수신거부 안내가 한글+영문이고 원클릭이다
□ 야간 동의를 안 받았으면 21~08시 발송을 코드로 막았다
□ marketing_consent_at 컬럼이 있다
□ 2년 재확인을 어떻게 할지 정해 뒀다
```
