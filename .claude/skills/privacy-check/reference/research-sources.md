# Step 3 — 현행 기준 확인하기

**기준을 기억으로 쓰지 않는다.** 법령과 가이드라인은 개정된다. 실행할 때마다 확인하고 출처를 남긴다.

## 최소한 확인할 것

| 확인 대상 | 왜 |
|---|---|
| 개인정보보호위원회 **「개인정보 처리방침 작성지침」 최신판** | 필수 기재사항의 실무 기준. **생성형 AI 서비스 부록**과 수탁자 유형화 기재 허용 여부를 확인 |
| **개인정보 보호법 제30조** 제1항 각 호 | 필수 기재사항의 법적 근거. 호가 추가·변경되었는지 |
| **개인정보 보호법 시행령** (제30조 제1항 8호 위임 사항) | 시행령으로 정한 추가 기재사항 목록 |
| **개인정보 보호법 제15조 제2항** | 동의 시 알려야 할 4가지 |
| **정보통신망법 제50조** | 광고성 정보 전송 요건 전체 |
| 최근 개정·시행 예정 사항 | 시행일이 다가오는 개정이 있으면 리포트에 미리 알린다 |

## 검색어

```
개인정보 처리방침 작성지침 최신 개인정보보호위원회
개인정보보호법 제30조 개인정보 처리방침 필수 기재사항
개인정보보호법 시행령 제31조 처리방침 기재사항
개인정보 처리방침 생성형 AI 부록
정보통신망법 제50조 광고성 정보 전송 수신동의
광고성 정보 전송 가이드라인 야간 (광고) 표기
개인정보 국외 이전 고지 동의
개인정보보호법 개정 시행 [현재 연도]
```

## 출처 신뢰도 순서

1. **개인정보보호위원회 / 개인정보보호 포털** (pipc.go.kr, privacy.go.kr) — 지침·가이드라인 원문
2. **국가법령정보센터** (law.go.kr) — 조문 원문
3. **한국인터넷진흥원(KISA)** — 스팸 대응, 광고성 정보 전송 안내
4. 법무법인·법률신문 해설 — 개정 요약 파악용. **여기서 본 내용은 1~2번에서 원문을 확인한 뒤 인용한다**
5. 블로그·SaaS 업체 가이드 — 방향 잡기용. 근거로 쓰지 않는다

## 조문 읽을 때의 실무 팁

- **law.go.kr의 검색 결과 페이지는 본문이 안 나온다.** 검색 UI만 잡힌다. 조문 직접 URL 형식(`law.go.kr/법령/개인정보보호법/제30조`)을 쓰거나, `casenote.kr/법령/...` 처럼 본문이 정적으로 실리는 곳을 쓴다.
- 조문에 "**대통령령으로 정하는**"이 나오면 시행령을 한 단계 더 봐야 한다. 거기서 실제 요건이 정해진다.
- "**해당하는 경우에만 정한다**"가 붙은 호는 인벤토리를 보고 해당 여부부터 판단한다. 해당 없으면 없다고 리포트에 적는다 — 조용히 빼면 빠뜨린 것과 구분이 안 된다.
- 개정 조문은 **시행일**을 확인한다. 공포됐지만 아직 시행 전이면 그렇게 표시한다.

## 확인 결과를 이렇게 기록한다

리포트 하단 "점검 기준" 절에 그대로 들어간다.

```markdown
## 점검 기준

- 확인 시점: 2026-08-08
- 개인정보 보호법 제30조 제1항 — https://... (확인일 기준 현행)
- 개인정보 처리방침 작성지침 (개인정보보호위원회, 2026-04-24 개정) — https://...
- 정보통신망법 제50조 — https://...

법령은 개정될 수 있습니다. 이 리포트는 위 시점의 기준으로 작성되었습니다.
```

## 확인이 안 될 때

웹 접근이 막히거나 원문을 못 찾으면 **모르는 채로 단정하지 않는다.**

- 해당 항목을 `❓ 확인 필요`로 두고, 무엇을 확인해야 하는지와 어디서 볼 수 있는지를 적는다
- "확인하지 못했다"고 리포트에 명시한다. 기억으로 채워 넣지 않는다
- 점검 자체를 중단할 필요는 없다. 확인된 부분까지 진행하고 범위를 밝힌다
