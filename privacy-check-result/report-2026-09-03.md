|---|---|---|---|---|---|---|
| 이메일·이름·프로필사진 | 구글 로그인(OAuth/GIS) | Neon `users` (싱가포르) | 로그인 화면 고지 문구만 ⚠️ | Google, Neon | 이메일 요청 시 수동 삭제 | `src/auth.ts`, `src/db/schema.ts` |

**확인된 "없음"** (근거와 함께):
- 분석·광고 도구 없음 — GA/GTM/픽셀/Sentry 등 코드에 부재. 외부 스크립트는 구글 로그인(gsi/client) 하나뿐
- AI API로 나가는 사용자 입력 없음 — OpenAI/Anthropic 호출 코드 부재
- 메일·SMS 발송 API 없음 — Resend/SendGrid/Solapi 등 부재 → **마케팅 수신동의 해당 없음**
- 파일 업로드 없음, 결제 없음

### ⚠️ 사용자가 예상 못 할 만한 수집 항목
- **IP·접속기록**: Vercel이 호스팅 로그로 자동 수집. 방침 6장(국외 이전 표)에는 "접속 기록"이 있는데 **1장(수집 항목 표)에는 없음** → 아래 🟡-1

### ❓ 확인 필요
- **프로덕션 `AUTH_SECRET` 설정 여부** — 코드에 미설정 시 `"dev-only-secret"` 폴백이 있음(`src/auth.ts`). Vercel 환경변수에 실제 시크릿이 있는지 대시보드에서 확인할 것. 미설정이면 세션 위조 가능 → 안전성 확보조치의 실질 위반이 됨
- **Neon 백업 보존 기간** — "삭제 요청 시 파기"가 백업본에도 미치는지. Neon 콘솔의 백업/PITR 설정 확인

## 2. 점검 결과

### 🔴 즉시 — 동의 시 고지 4가지 미달 (개인정보 보호법 제15조 제2항)

- **무엇이**: 로그인 화면(`src/app/login/login-card.tsx:210-216`)에 "로그인하면 개인정보처리방침에 동의한 것으로 봐요"라는 문구와 링크만 있음.
- **왜 문제인가**: 수집·이용 동의를 받을 때는 ① 수집·이용 목적 ② 수집 항목 ③ 보유·이용 기간 ④ 동의 거부권과 거부 시 불이익, 4가지를 **동의 화면에서** 알려야 한다. 처리방침 링크로 갈음할 수 없다. 간편(소셜) 가입도 동일하게 적용된다.
- **어떻게 고치나**: 로그인 버튼 아래 고지 문구를 4가지가 포함된 형태로 교체 — `consent-copy.md`에 바로 붙일 문구를 만들어 두었다.

### 🟡 곧 — 세 가지

1. **자동 수집(IP·접속기록)이 수집 항목 표에 없음** — 방침 1장에는 세션 쿠키만 있는데, Vercel이 IP·접속기록을 자동 수집한다(방침 6장 국외 이전 표에는 이미 등장). 1장 표에 "자동 수집: 접속 IP, 접속 기록" 행을 추가해 문서 내부 정합과 고지를 맞출 것. → `privacy-policy-draft.md`에 반영해 둠
2. **국외 이전의 법적 근거 미기재** — 시행령 제31조는 국외 이전 시 "이전 근거"(법 제28조의8 제1항 각 호)를 방침에 적도록 한다. 현재 6장에 근거 문구가 없음. "정보주체와의 계약 체결·이행을 위한 처리위탁·보관"(제28조의8 제1항 제3호 유형) 문구 추가 권장. → 초안에 반영해 둠
3. **동의 사실 기록 없음** — `users` 테이블에 동의 시점·버전 컬럼이 없어 나중에 "동의받았다"를 입증할 수 없다. `privacy_agreed_at timestamptz`, `privacy_policy_version text` 컬럼 추가 권장(가입 upsert 시 기록, `src/auth.ts`의 jwt 콜백).

### 🟢 개선

- **삭제 요청 운영 절차** — 방침은 "요청 시 지체 없이 파기"로 정직하게 기재되어 있고 창구(이메일)도 실재함 ✅. 다만 실제 요청이 오면 `users` + 연관 테이블 + Neon 백업까지 지우는 절차를 미리 정리해 둘 것. 추후 앱 내 탈퇴 기능 추가 검토
- **변경 이력 관리** — 방침 개정 시 이전 버전을 확인할 수 있게 하는 것이 권장됨(현재 최초 시행일 병기까지는 되어 있음)

### ✅ 잘 되어 있는 것

- 방침 존재, 로그인 없이 접근 가능(미들웨어 공개 경로), 푸터·로그인 페이지 링크, 별도 문서, 시행일 표기 — 4-1 전 항목 통과 (배포 URL에서 실측 확인)
- 제30조 필수 기재사항: 목적·보유기간·파기·위탁·국외이전·권리행사·보호책임자(최주희, 실명)·쿠키 거부 방법·안전성 확보조치·침해 구제 — 모두 기재
- 수집 항목이 코드와 일치(이메일·이름·프로필사진, 그 외 수집 없음), 위탁/제3자 제공 구분 정확(Vercel·Neon을 위탁으로 분류)
- 제34조 인용이 "조까지만"이라 2026-09-11 시행 개정(유출 가능성 통지제 신설, 항 개편)에도 문구 수정 불필요
- 마케팅 수신동의: **해당 없음** — 광고성 발송 수단이 코드에 전혀 없음. 단, 뉴스레터 하나만 붙여도 정보통신망법 제50조 적용 대상이 되므로 그때 다시 점검할 것
