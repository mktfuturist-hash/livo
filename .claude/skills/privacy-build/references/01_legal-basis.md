> 조사 기준일 2026년 8월 30일. 1차 출처는 국가법령정보센터(law.go.kr), 가이드라인은 pipc.go.kr / kisa.or.kr / ftc.go.kr.

## 1. 개인정보 처리방침

### 개인정보 보호법 제30조 제1항 — 법정 기재사항

| 호 | 기재사항 | 조건 |
|---|---|---|
| 1 | 개인정보의 처리 목적 | 필수 |
| 2 | 개인정보의 처리 및 보유 기간 | 필수 |
| 3 | 개인정보의 제3자 제공에 관한 사항 | 해당 시 |
| **3의2** | 개인정보의 파기절차 및 파기방법 | 필수 |
| **3의3** | 민감정보의 공개 가능성 및 비공개 선택 방법 | 해당 시 |
| 4 | 개인정보처리의 위탁에 관한 사항 | 해당 시 |
| **4의2** | 가명정보의 처리 등에 관한 사항 | 해당 시 |
| 5 | 정보주체와 법정대리인의 권리·의무 및 행사방법 | 필수 |
| 6 | 개인정보 보호책임자의 성명 또는 담당 부서 연락처 | 필수 |
| 7 | 인터넷 접속정보파일 등 자동 수집 장치의 설치·운영 및 그 거부에 관한 사항 | 해당 시 |
| 8 | 그 밖에 대통령령으로 정한 사항 | 필수 |

**`3의2` `3의3` `4의2` 같은 가지번호가 실제로 있다. 1~8로 나열하면 틀린다.**

같은 조 나머지 항
- 제2항 — 수립·변경 시 정보주체가 쉽게 확인할 수 있도록 공개
- 제3항 — 처리방침과 계약 내용이 다르면 **정보주체에게 유리한 것**을 적용
- 제4항 — 보호위원회가 표준 작성지침을 정해 권장 가능

### 시행령 제31조 제1항 — 위 제8호의 "대통령령으로 정한 사항"

| 호 | 내용 |
|---|---|
| 1 | **처리하는 개인정보의 항목** |
| 2 | 국외 이전의 근거와 관련 사항 |
| 3 | **개인정보의 안전성 확보 조치**에 관한 사항 |
| 4 | 국외에서 국내 정보주체의 개인정보를 직접 수집해 처리하는 경우 그 국가명 |

**1인 개발자가 가장 자주 빠뜨리는 게 1호와 3호다.** 법률 본문이 아니라 시행령에만 있어서 놓친다.

### 공개 방법 (시행령 제31조 제2·3항)

- 원칙 — **인터넷 홈페이지에 지속적으로 게재**
- 홈페이지가 없을 때만 사업장 게시 / 관보·신문 게재 / 간행물 게재 / 계약서 발급

웹서비스라면 **푸터 링크가 표준 구현**이다.

### 개인정보 보호책임자(CPO)

- **법 제31조 제1항 단서** — 종업원 수·매출액 등이 대통령령 기준에 해당하면 지정하지 않을 수 있다
- **시행령** — 그 기준은 **「소상공인기본법」 제2조제1항에 따른 소상공인** ⚠️ 항 번호 미확정
- **법 제31조 제2항** — 지정하지 않으면 **사업주 또는 대표자가 개인정보 보호책임자가 된다**

> **지정 의무 면제 ≠ 기재 의무 면제.** 제30조 제1항 제6호는 그대로 살아 있으므로, **본인 이름과 연락처를 처리방침에 적어야 한다.** 가장 흔한 오해다.

### 과태료 (법 제75조 제4항)

| 위반 | 근거 | 금액 |
|---|---|---|
| 처리방침을 정하지 않거나 공개하지 않음 (제30조 제1·2항) | 제75조 제4항 제8호 | **1천만원 이하** |
| 개인정보 보호책임자 미지정 (제31조 제1항) | 제75조 제4항 제9호 | 1천만원 이하 |

## 2. 마케팅 수신동의 — 정보통신망법 제50조

| 항 | 내용 |
|---|---|
| 제1항 | **명시적 사전 동의(옵트인)** 원칙 |
| 제1항 단서 1호 | 거래관계 예외 — 거래로 직접 수집한 연락처에, **거래 종료일부터 6개월 이내**, **동종** 재화등의 광고 ⚠️ 시행령 조문번호 미확정 |
| 제2항 | 수신거부·철회 의사표시자에게 전송 금지 |
| 제3항 | **오후 9시 ~ 다음 날 오전 8시** 전송은 **별도 사전 동의**. 대통령령이 정한 매체는 예외(전자우편) ⚠️ |
| 제4항 | 전송자 명칭·연락처, 수신거부 방법 등 **표시의무** |
| 제5항 | 금지행위 5종 — 수신거부 회피·방해 / 자동 연락처 생성 / 자동 등록 / 신원·출처 은폐 / 기망 회신 유도 |
| 제6항 | 수신거부 비용을 수신자에게 부담시키지 말 것 |
| 제7항 | 동의·거부·철회 처리 결과를 수신자에게 알릴 것 |
| 제8항 | **정기적으로 수신동의 여부 확인** |

### 표시의무 상세 — 시행령 [별표 6]

**공통**
- **"(광고)" 표시** — 공백·기호·문자를 넣어 회피 금지 (`(광 고)`, `[AD]` 모두 위반)
- 수신거부·철회 시 **연락처 외의 정보를 요구하지 말 것**

**전자우편**
- "(광고)"를 **제목이 시작되는 부분**에
- 본문에 전송자 명칭·이메일·전화번호·주소
- 수신거부 안내문을 **한글과 영문으로** + 기술적 조치(원클릭 수신거부)

**SMS · 앱 푸시 · 메신저 (음성 외 형태)**
- **"(광고)"**, 전송자 명칭, 전화번호 또는 주소
- **정보의 끝부분**에 수신거부·철회 방법 및 **무료임을 명시**

실무 예시
```
(광고) [서비스명]
...본문...
무료수신거부 080-XXX-XXXX
```
자주 지적되는 오류 — "무료" 문구 누락, "(광고)"가 본문 중간에 위치.

### 2년마다 재확인 — 시행령 제62조의3

> ① 사전 동의를 받은 자는 **수신동의를 받은 날부터 2년마다** 수신동의 여부를 확인하여야 한다.
> ② 확인 시 고지사항 — 1. 전송자의 명칭 2. 수신동의 사실과 **동의한 날짜** 3. 유지 또는 철회 의사표시 방법

**서비스 오픈일이 아니라 개별 수신자의 동의일 기준이다.** 회원마다 시계가 따로 돈다. `marketing_consent_at`을 저장하지 않으면 이행이 물리적으로 불가능하다.

### 채널별 차이

| 채널 | 야간(21~08) 별도 동의 | 비고 |
|---|---|---|
| 이메일 | **예외** (동의 불요) ⚠️ | "(광고)"는 제목 앞. 수신거부 안내 한글+영문 |
| SMS · LMS | **적용** | 무료 수신거부 번호 필수 |
| 앱 푸시 | **적용** | **OS 알림 허용 ≠ 마케팅 수신동의.** 별도로 받아야 함 |
| 카카오 알림톡 | 해당 없음 | **정보성.** 채널 미추가자에게도 발송 가능. 광고 금지 |
| 카카오 친구톡 | **적용** | **광고성.** 채널 친구 대상. 수신동의 + "(광고)" 필요 |

**알림톡의 함정** — 카카오 기준으로 정보 중심이라도 **특가·할인·프로모션·이벤트가 혼재하면 광고성**이 된다. 배송 안내 하단에 쿠폰을 붙이는 순간 광고성이다.

### ⚠️ 매체별 동의 (2026년 쟁점)

KISA 7차 안내서 기준으로 **문자와 메신저는 별개 매체**다. 동의 시 특정 매체를 선택했다면 **그 매체로만** 광고를 전송해야 한다. "SMS 마케팅 수신동의"를 받아 두고 카카오톡으로 광고를 보내는 것은 위법 소지가 있다.

→ 동의 UI에서 **채널을 명시하거나 분리**할 것.

### 과태료 (제76조 제1항, 3천만원 이하)

| 호 | 위반 |
|---|---|
| 제7호 | 제50조 제1~3항 — 동의 없이 전송 / 수신거부자에게 전송 / 야간 별도 동의 없이 전송 |
| 제8호 | 제50조 제4항 — 표시의무 미이행 |
| 제9호 | 제50조 제6항 — 수신거부 비용 부담 |
| **제9의2호** | 제50조 제8항 — **2년마다 재확인 미실시** |

**제50조 제5항 위반은 과태료가 아니라 형사처벌** — 1년 이하 징역 또는 1천만원 이하 벌금. ⚠️ 근거 조문 항·호 미확정.

실제 부과 기준 (단속기관 공표) — 1차 750만원 / 2차 1,500만원 / 3차 3,000만원.

## 3. 이용약관

### 이용약관은 의무인가 — 두 법을 구분한다

| 법 | 조문 | 요구 | 성격 |
|---|---|---|---|
| **전자상거래법** | **제10조 제1항 제5호** | 사이버몰에 **이용약관을 표시** | 표시 의무 |
| 전자상거래법 | 제10조 제1항 1~4·6호 | 상호·대표자명·주소·전화·이메일·**사업자등록번호** | 표시 의무 |
| 전자상거래법 | **제13조 제1항** | 표시·광고 시 상호·대표자명·연락처·**통신판매업 신고번호와 신고기관** | 정보 제공 의무 |
| **약관규제법** | **제3조** | 약관의 작성·명시·교부·설명 | 약관을 쓸 때의 절차 의무 |

**주의** — 제13조 제1항에는 **사업자등록번호가 없다.** 사업자등록번호는 제10조에, 통신판매업 신고번호는 제13조에 있다. 근거 조문이 다르다.

### 약관규제법 제3조 — 실질 내용

| 의무 | 내용 |
|---|---|
| 작성 | **한글로**, 표준화·체계화된 용어로, **중요한 내용을 부호·색채·굵고 큰 문자로 명확히 표시** |
| 명시·교부 | 계약 체결 시 약관 내용을 분명히 밝히고, **고객이 요구하면 사본 교부** |
| 설명 | 약관의 **중요한 내용**을 고객이 이해할 수 있도록 설명 (계약 성질상 현저히 곤란하면 예외 — 제3항) |
| **위반 효과** | **해당 약관을 계약의 내용으로 주장할 수 없음** |

> **위반 효과가 실무적으로 가장 무섭다.** 과태료가 아니라 **조항 자체가 무효화**된다. 환불 제한, 책임 제한, 자동 갱신을 아무리 잘 써 놔도 가입 플로우에서 제대로 보여주지 않았다면 분쟁 시 들 수 없다.

구현 지침
- 가입 버튼 옆에 약관 전문 링크 (스크롤 가능한 모달 권장)
- 동의 체크박스를 **항목별로 분리** — 이용약관 / 개인정보 처리방침 / (선택) 마케팅
- 중요 조항(환불·해지·책임 제한·자동결제)은 **볼드 또는 별도 색상**
- 동의 시점·버전·IP를 로그로 저장 — 분쟁 시 "명시했다"의 유일한 증거

### 통신판매업 신고

**전자상거래법 제12조 제1항** — 관할 시장·군수·구청장에게 신고.
**단서** — 거래횟수·거래규모 등이 **공정거래위원회 고시** 기준 이하면 면제.

면제 기준 ⚠️ 고시 원문 미확정 (언론·소비자24 기준)
- 직전연도 통신판매 **거래횟수 50회 미만**
- 「부가가치세법」상 **간이과세자**

고시: 공정거래위원회고시 제2022-4호 「통신판매업 신고 면제 기준에 대한 고시」

판단 흐름
```
유료 결제가 있는가?
├─ 아니오 → 신고 불필요 (통신판매 자체가 없음)
└─ 예 → 직전연도 거래 50회 미만이거나 간이과세자인가?
    ├─ 예 → 면제 가능 (⚠️ 고시 원문 확인)
    └─ 아니오 → 신고 필요
```

**법적 면제와 상거래상 요구는 별개다.** 면제 대상이어도 PG사·결제대행사가 신고번호를 요구하는 경우가 많다.

### 공정거래위원회 표준약관

**전자상거래(인터넷사이버몰) 표준약관 — 제10023호**, 총 24개 조문.
널리 유통되는 판본은 2015. 6. 26. 개정본. ⚠️ 현행 최신 개정일과 공정위 직접 다운로드 URL은 미확인.
게시판: https://www.ftc.go.kr/www/selectBbsNttList.do?bordCd=201&key=202

**표준약관은 강제가 아니다.** 그리고 **제10023호는 물리적 재화 판매(공급·반품·환급) 전제라 SaaS·구독형에 그대로 쓰면 맞지 않는다.**

### 무료 서비스에도 이용약관이 필요한가

| 법 | 무료 서비스 적용 |
|---|---|
| 전자상거래법 제10조 | 적용 안 될 가능성 높음 ⚠️ (거래 전제) |
| 전자상거래법 제12조 (통신판매업 신고) | **적용 안 됨** |
| 약관규제법 제3조 | **적용됨** — 약관을 쓰는 이상 유·무료 불문 ⚠️ |
| **개인정보 보호법 제30조** | **적용됨** — 무료라도 개인정보를 처리하면 처리방침 의무 |

**법이 시켜서가 아니라 방어 수단이 없어서 만든다.**

약관이 없으면 방어 불가능한 것 — 서비스 중단·종료의 권리 / 계정 정지·삭제 사유 / 이용자 생성 콘텐츠 처리 권한 / 책임 제한 / 준거법·관할 / **약관 변경 절차**.

**무료 서비스야말로 「약관 변경 조항」이 가장 중요하다.** 나중에 유료화하거나 무료 플랜을 축소할 때, 사전에 정해 둔 변경 절차가 없으면 기존 이용자 전원에게 개별 동의를 다시 받아야 한다.

## 4. 흔한 실수

### 처리방침
1. 처리방침에 없는 항목을 실제로 수집 (방침엔 이메일만, 실제론 전화번호·기기정보)
2. **"처리하는 개인정보 항목" 자체를 누락** — 시행령에만 있어 놓침
3. **"안전성 확보 조치" 서술 누락**
4. **CPO 성명·연락처 미기재** — 소상공인 지정 면제와 기재 의무를 혼동
5. **국외 이전 미기재** — AWS·Vercel·Supabase·OpenAI. **바이브 코딩 스택 최대 누락**
6. 쿠키·로그 등 자동 수집 장치 미기재 — GA·Amplitude 붙이면 해당
7. **템플릿 복붙** — 실제 없는 조항(위탁사·CCTV)을 남겨 둠
8. 만들어 놓고 홈페이지에 상시 게재하지 않음

### 마케팅 수신동의
9. 동의 항목 일괄 체크 / 필수 항목에 마케팅 동의를 끼워 넣기
10. **"혜택 알림", "정보 제공" 같은 모호한 표현으로 동의 받기** (KISA 7차가 명시적으로 지적)
11. "(광고)" 누락 또는 회피 표기
12. 무료 수신거부 안내 누락 / "무료" 문구 빠짐
13. 야간 발송에 별도 동의 없음
14. **2년 재확인 미실시**
15. **동의 일자를 저장하지 않음**
16. **SMS 동의로 카카오톡 광고 발송**
17. 앱 푸시 OS 권한을 마케팅 동의로 간주
18. 알림톡에 쿠폰·프로모션 끼워 넣기
19. **일방 지급 쿠폰·적립금 안내를 정보성으로 발송** (KISA 7차: 사전 동의 필요)
20. 수신거부 시 로그인·본인인증 요구 → **형사처벌 대상**

### 이용약관
21. 링크만 걸고 중요 조항을 강조 표시하지 않음
22. 이용약관과 개인정보 처리방침 동의를 **하나의 체크박스로**
23. 사이버몰에 사업자 정보 미표시
24. 통신판매업 신고번호를 표시·광고에 미표기
25. 표준약관 제10023호를 SaaS에 그대로 사용
